# Escalas das Lojas

Site onde cada gerente vê, ajusta e lança a escala 5x2 da sua loja.

- Entra com o usuário da loja. Cada gerente só vê a própria loja.
- A escala já vem pronta (escala padrão). O gerente muda horário, folga e intervalo; o site confere as regras na hora.
- "Lançar escala" trava a escala e avisa o escritório.

Os dados ficam no banco, protegidos por login. Nada de dados de funcionários neste repositório.
